Featured Projects

ReClaim : Lost and Found System

An intelligent web-based platform designed to reconnect users with lost items through automated matching and verification. This system was developed using PHP, CSS, and JavaScript for the backend and frontend functionalities, integrating an AI-based similarity detection algorithm to analyze and compare descriptions provided by item finders and claimers. By leveraging natural language processing techniques, the platform can identify matching patterns in item descriptions, helping to verify ownership and reduce false claims. The project aims to enhance the efficiency and reliability of lost-and-found systems through intelligent automation and user-friendly design.

Personal Budget Planner

A streamlined web-based financial management tool developed using PHP, CSS, and JavaScript to help users track their income and expenses while planning their personal budgets effectively. The system includes goal-oriented saving features that allow users to set financial targets and monitor their progress over time. Additionally, the platform provides smart financial spending suggestions based on user input to encourage better budgeting decisions and promote financial awareness. Through interactive dashboards and educational insights, this project aims to support users in learning fundamental financial management practices and developing healthier spending habits.

Mail Rush

A simple neighborhood delivery game developed using Unity, where players take on the role of a mail carrier tasked with delivering mail to various houses while avoiding being chased by dogs. The game focuses on basic gameplay mechanics such as movement, obstacle avoidance, and time-based challenges, providing an engaging and interactive experience. This project demonstrates fundamental game development concepts, including character control, AI-driven enemy behavior, and level design within the Unity game engine.
